== Install

Create the POD.

[source,bash]
----
podman pod create --label app=dolibarr \
  --label app.kubernetes.io/name="dolibarr" \
  --label app.kubernetes.io/instance="dolibarr" \
  --label app.kubernetes.io/version="23.0.4" \
  --label app.kubernetes.io/component="application" \
  --label app.kubernetes.io/part-of="dolibarr" \
  -p 7180:80 -p 15432:5432 -p 13306:3306 \
  dolibarr 
----

Deploy the database (MariaDB).

[source,bash]
----
ansible-playbook mariadb/podman/ansible/podman-install-playbook.yaml \
  -e @dolibarr/podman/ansible/defaults/main.yaml \
  -e db_password="${DB_PASSWORD:-dolibarr}"
----

Deploy the database (PostgreSQL).

[source,bash]
----
ansible-playbook pgsql/podman/ansible/podman-install-playbook.yaml \
  -e pod_name=dolibarr \
  -e db_name=dolibarr \
  -e db_user=dolibarr \
  -e pgsql_version="17.1" \
  -e db_password="${DB_PASSWORD:-dolibarr}"
----

Deploy the Dolibarr application.

[source,bash]
----
ansible-playbook dolibarr/podman/ansible/dolibarr-install-playbook.yaml \
  -e @dolibarr/podman/ansible/defaults/main.yaml
----

If deploying with PostgreSQL proceed with the manual first installation using 
 the URL http://localhost:7180/install/ where `7180` is the port defined 
 using the `dolibarr_host_port` variable.

== Uninstall

Uninstall Dolibarr.

[source,bash]
----
ansible-playbook dolibarr/podman/ansible/dolibarr-uninstall-playbook.yaml \
  -e pod_name=dolibarr
----

Uninstall the PostgreSQL database.

[source,bash]
----
ansible-playbook pgsql/podman/ansible/podman-uninstall-playbook.yaml \
  -e pod_name=dolibarr \
  -e db_name=dolibarr
----

== Upgrade

Uninstall the Dolibarr pod.

Redeploy the Dolibarr Pod using a new version, _e.g._ `-e dolibarr_version="22.0.4"`.

Open the Dolibarr URL and follow the on screen instructions to update the database.
